# Weather Service App

## Overview
.NET application consuming OpenWeather API to display weather data.

## Tech Stack
- C#
- .NET / ASP.NET Core (jeśli użyte)
- REST API
- JSON
- HttpClient

## Features
- Fetch weather data from OpenWeather API
- Display current weather conditions
- Error handling and retry logic

## Architecture

- Separation of concerns (if applicable)
